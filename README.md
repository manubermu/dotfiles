## 🚀 Quick Start

```bash
# Clone this repository
git clone https://github.com/manubermu/dotfiles.git

# Navigate to the directory
cd dotfiles

# Make the install script executable and run it
chmod +x install.sh && ./install.sh
```

## ✨ Features

- 🍺 Automated Homebrew installation and package management
- 📱 Curated collection of essential macOS applications
- ⚙️ Sensible macOS system defaults
- 🔧 Git configuration
- 🐚 ZSH setup with modern plugins
- 📁 Organized development environment setup

## 📖 What's Inside

### System Setup
- **Homebrew**: Package manager for macOS
- **Applications**: Managed through Brewfile
- **macOS Configurations**: Optimized system settings
- **ZSH Configuration**: Enhanced shell experience

### Directory Structure
```
.
├── config/          # System configurations
├── install/         # Installation scripts
└── zsh/            # ZSH configuration
```

## 🛠 Installation

1. Open Terminal
2. Clone the repository:
   ```bash
   cd ~/Documents
   git clone https://github.com/manubermu/dotfiles.git
   cd dotfiles
   ```
3. Run the installation script:
   ```bash
   ./install.sh
   ```
4. Choose from the available options:
   - Install Homebrew
   - Install Applications
   - Configure macOS
   - Install/Configure ZSH
